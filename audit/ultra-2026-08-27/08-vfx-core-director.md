- **`worldFixedDisplacement` контракт:** `anchorOffset` хранит полный displacement, `direction` — нормализованная версия того же вектора. `TodoVfxRecipes.tripleSwap` читает `anchorOffset.length()` как `edgeLength` и `direction` как ориентацию — правильно, т.к. `direction` нормализован. `NailTrapRuntime.collapseCue` корректно использует `worldFixedDisplacement(from, to-from)`.
- **Intensity clamping:** фабрики клампят `Math.max(1,intensity)`, рецепты дополнительно `Math.max(1, Math.min(7, ...))` — дублирование без вреда, но `clampIntensity` в `ProjectJjkMegaNailRuntime` тоже `max 1 min 7` — тройной clamp.

- **Единственный receiver.** `JujutsuClientNetworking.registerReceivers` регистрирует ровно один `VfxCuePayload.TYPE → VfxDirector.receive` (`src/client/java/jujutsu/mod/client/network/JujutsuClientNetworking.java:20-21`). `grep` по `registerGlobalReceiver.*Vfx` не нашёл per-effect receivers. Контракт «no per-effect receivers» соблюдён — весь VFX идёт через director.
- **Инициализация детерминирована.** `JujutsuModClient.onInitializeClient:25 VfxDirector.initialize()` → `26 registerHudContribution(ability_hud)` → `29 JujutsuCharacterClients.registerAll()` → каждый `CharacterClientDefinition.registerClientHooks()` → `NobaraVfxRecipes.register()/TodoVfxRecipes.register()/MegumiVfxRecipes.register()`. - **7 каналов, без lifecycle-менеджеров на эффект.** `WORLD/HUD/CAMERA/FIRST_PERSON/PARTICLES/SOUND/POST_PROCESS` — все статичные синглтоны в `VfxDirector`, без `EffectManager`/`LifecycleManager` на каждый эффект. `VfxHudChannel` имеет ровно один `HudElementRegistry.attachElementAfter(MISC_OVERLAYS, jujutsumod:vfx_overlay, renderHud)` — второй `HudRenderCallback` запрещён контрактом и не найден.
- **Transient vs persistent разделено верно.** Transient: `VfxCue → recipe → channels` (one-shot `VfxInstance.start` один раз, `isOpeningBeat` гейт, `isExpired` дроп). Persistent: `ProjectJjkNailRenderer` (entity renderer), `NobaraTargetHud` / `MegumiCooldownHud` / `TodoStoneHud` как `registerHudContribution` (HUD contributions, а не отдельные HUD callbacks), `ShadowBodySink`/`HiddenBodyRenderGate` (TTL-кэши, fail-open). `level.sendParticles` для `hairpin trail` — спорный но изолированный transient trail, не ломающий архитектуру.

Рецепты с `isOpeningBeat(initialAgeTicks)` не спавнят частицы повторно на поздних cue, но `swapAfterimage/swapArrival` намеренно без гейта (world flash живёт по `gameTime` seek). `VfxTimeline.startedAtMillis/Nanos` бэкдейтит `startedAt` на `initialAgeTicks` для realtime каналов (camera/HUD/postProcess) — консистентно.

### 4) Вердикт

**PASS WITH CAVEATS**

VFX Core реализован образцово для текущего масштаба (49 live ids, 3 vessel, 7 каналов): единственный S2C payload, единственный receiver, единственный HUD element, 7 каналов без per-effect менеджеров, корректный late-cue seek/expiry, fail-open TTL для hide/sink, детерминированные часы для тестов, vessel seam не нарушен.
