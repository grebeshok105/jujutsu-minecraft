### 3) Позитивные наблюдения

- **30 nails cap корректно реализован и compile-time константа:** `EmbeddedNailRegistry.track()` с `prune()` + `while (size>30) { oldest.next(); discard(); }` (L112-141) — FIFO по `LinkedHashMap` insertion order, `removeIf(isLiveLoadedNail)` перед проверкой cap гарантирует что мёртвые/выгруженные гвозди не занимают слоты. `ProjectJjkNobaraProfile.MAX_EMBEDDED_NAILS_PER_OWNER=30` — единый source of truth, используется только здесь.
- **Leash 10т check реализован точно по ТЗ:** `MegumiSummonRuntime.recoverLeash()` line 531 `if (gameTime % LEASH_RETRY_TICKS !=0) return` + `distanceToSqr > 32*32` + `findLeashPosition()` с проверками loaded, floor-supported (`isFaceSturdy`), collision-free (`noBlockCollision` via `isSafe`), hazard (`!fire/lava`, `!tags`), entityCollision. Throttling соблюдён — не каждый tick.
- **Shadow grip — server-authoritative, без ручного scrub, через attribute modifiers:** `MegumiShadowTrapRuntime.gripBodies()` применяет `MEGUMI_SHADOW_GRIP` (`MOVEMENT_SPEED -0.75 ADD_MULTIPLIED_TOTAL`, `JUMP_STRENGTH -1.0`) duration 8t; выход из зоны — expire без cleanup. `MegumiProfile` документирует `SHADOW_TRAP_GRIP_REFRESH_TICKS=8`. Архитектурно верно, хотя gate пропущен (см. находка).
- **Pool radius анимация вынесена из profile в VFX cue intensity:** `radiusIntensity() = round(RADIUS*10)` (2.6→26) передаётся в `VfxCues.worldFixed/anchored`, рецепты не дублируют число. Zone pulse `40t` (`SHADOW_TRAP_ZONE_PULSE_TICKS`) и grip cue `20t` — разные периоды, не каждый tick. `NailTrapRuntime` аналогично: `gameTime %40==0` re-emit `NAIL_TRAP_ARMED` intensity 1 (silent pulse), реальный `intensity 3` только на place.
- **Отсутствие аллокаций на cast-пути где возможно:** `NailTrap.findPlacements()` использует stack-local `Vec3` и `BlockHitResult` без коллекций кроме `result` (3 элемента), `groundHit()` использует `level.clip()` без аллокаций списков. `ProjectJjkNobaraRuntime.findPreparedNails()` с `getEntities(player, bounds, predicate)` + `sorted+limit(8)` — ограничено 8, не сканирует весь мир.
- **Precomputed леash offsets:** `MegumiGroundSafety.LEASH_OFFSETS = buildLeashOffsets(3)` — статически сортированные по `distanceSquared then x then z`, ring-by-ring, `List.copyOf` — immutable, строится один раз. `VERTICAL_OFFSETS = List.of(0,1,-1,2,-2,3,-3)` — также константа, без пересоздания.
- **Tick handlers зарегистрированы один раз, без дублирования:** все `ServerTickEvents.END_SERVER_TICK.register(...)` в `register()` — `NailTrapRuntime`, `MegumiShadowTrapRuntime`, `MegumiSummonRuntime`. Нет подписок per-player, нет утечки слушателей. `SERVER_STOPPING`/`DISCONNECT`/`AFTER_DEATH` cleanup симметричны.
- **Compiled code / профили:** `TodoProfile`, `MegumiProfile`, `ProjectJjkNobaraProfile` — `static final` primitives, JIT-константы, без reflection. `nailDepthMultiplier()` — `switch` с `Math.clamp`, `detonateDamage()` — inline math, `launchDelayForIndex()` — `max(0,index)*4`. Нет boxing в профилях.
- **Client hot path throttled:** `NobaraEspState.REFRESH_INTERVAL_TICKS=2` (10 Hz) вместо каждый tick, `isNobara` check ранний return `Map.of()`, `clientTickMegaChargeVortex` — только для `isMegaNail && !isLaunched` (редкий объект, 1 per cast).

### 4) Вердикт

**PASS WITH CAVEATS**

**Обоснование:** Критические инварианты performance-среза соблюдены: cap 30 гвоздей enforced с FIFO discard и prune живых/загруженных гвоздей; leash recovery throttled на 10t с корректным safe-position поиском (loaded/floor/collision/hazard); pool radius не хардкодится в рецептах а едет через `radiusIntensity()` в cue; zone pulses throttled (40t trap / 40t shadow). Компилируемые профили — `static final`, без аллокаций. Однако в горячем пути сервера обнаружены avoidable аллокации/copies каждый tick: shadow grip без 8t gate (major), `Map.copyOf`/`new ArrayList` snapshot каждый tick в двух trap runtime, `selectTarget` скан+HashMap+stream каждый tick, leash `leashCandidates` материализация 343 Vec3 каждые 10t. На целевом 1-2 игрока это не приводит к FAIL (нагрузка мала, нет O(N^2) по игрокам), но при росте онлайна или числа trap/pack деградация линейна. Клиентский ESP скан `entitiesForRendering()` каждые 2t — также avoidable для больших миров.

**Приоритет фиксов:**
1. **P0 (major, 1ч):** Добавить `gameTime % 8` gate в `MegumiShadowTrapRuntime.gripBodies` — убирает `N` аллокаций `MobEffectInstance` + `addEffect` вызовов/tick.
2. **P0 (major, 1ч):** Убрать `Map.copyOf` snapshot в `MegumiShadowTrapRuntime.tick` и `NailTrapRuntime.tick` — итерировать напрямую или только при мутации.
3. **P1 (major, 2ч):** Троттлить `NailTrapRuntime.selectTarget` до 5-8t и переписать без `HashMap`+`stream().toList()` — один проход с `min` comparator без `toString`.
4. **P1 (major, 2ч):** Переписать `MegumiGroundSafety.leashCandidates()` без материализации `List<Vec3>` — вложенные циклы с early-return на первом `isSafe`.
5. **P2 (minor, 1ч):** Заменить `NailTrap.selectTarget` comparator `toString()` на `comparing(TargetCandidate::targetId)`.
6. **P2 (minor, 2ч):** Ввести `Set<UUID> TRAP_NAIL_IDS` для O(1) `isTrapNail` вместо линейного скана.
7. **P2 (minor, 1ч):** Увеличить `NobaraEspState.REFRESH_INTERVAL_TICKS` до 10 или перейти на event-driven обновление; кэшировать `ArrayList` вместо `new`.
