### 3) Позитивные наблюдения

- **Continuous между тиками реализован корректно.** `ShadowBodySink.sinkProgress/emergeProgress:104-126` читают `frameTime = level.getGameTime() + partialTick`, `CharacterSkinAnimationMixin:127-128` берёт `renderContext.partialTick()` из `extractRenderState`, `VfxCameraChannel:146` `gameTime + partialTick` — обе ветки (камера first-person и тело third-person) семплят один и тот же дробный clock, движение каждый кадр, не раз в тик. `smoothstep` на обеих сторонах даёт идентичную кривую.
- **Fail-open TTL — потерянный пакет не замораживает под землёй.** `ShadowBodySink:21,33-35` `UNDER_TTL 8t` + `windowTtlMillis = (duration+8)*50ms` и `entryOrExpired:143-147` lazy expire + `COMPLETE_TTL 8t:68`, `HiddenBodyRenderGate:32-42` lazy expire с `remove(entityId, value)` CAS — потеря `SHADOW_RIPPLE`/`SHADOW_EMERGE` дрейфует к видимому, не к вечной невидимости. `completeSink` idempotent, `beginEmerge` backdates из текущей глубины — плавный rise при прерывании mid-sink.
- **Veil и камера на одном clock.** `VfxCameraChannel.diveOffsetBlocks:160-168` и `diveFadeAlpha:171-179` делят `advanceDive:256-296` и константы `DIVE_SINK/UNDER/EMERGE` — `MegumiShadowDiveHud:24` `diveFadeAlpha(partialTick)` всегда в фазе с `HairpinCameraMixin:40` `diveOffsetBlocks(partialTick)`. `SINK 0→0.75 → UNDER 0.75→0.25 → EMERGING 0.45→0` veil совпадает с `0.85 → 0.35 → 0.5` камеры.
- **Third/first person разделены аккуратно.** `HairpinCameraMixin:41` `if (!detached && dive > 0.001f)` — только first-person, `CharacterSkinAnimationMixin:118-138` — только body `PlayerRenderState`, `MegumiShadowDiveHud:21` `isFirstPerson()` guard — veil тоже только first-person. В third-person body sink виден, камера стоит — vanilla path untouched. `detached` reverse (F5 зеркало) тоже без dip, корректно.
- **Vessel seam не нарушен, server-authoritative.** `ShadowBodySink`/`HiddenBodyRenderGate` не знают `JujutsuCharacter`, живут в `client/render`; рецепты в `MegumiVfxRecipes` вызывают их с `cue.anchorEntityId()` + `cue.startGameTime()` authoritative. `MegumiProfile.SHADOW_*_TICKS` — single source. `isOpeningBeat` guards + server re-emission `SHADOW_RIPPLE` каждые 5т вместо client re-tick.
- **Ripple TTL slack подобран верно.** `RIPPLE_HIDE_TTL 8t` при периоде 5т даёт 3т запаса на один потерянный пакет; `UNDER_TTL_TICKS=8` mirror. Комментарий `// 8 ticks keeps it with slack:21` и `// window itself plus one full hold TTL:32` документируют trade-off.
- **Backdate из текущей глубины — нет снапа.** `beginSink:45-50` backdates из `EMERGING` по `depth = 1 - progress`, `beginEmerge:83-88` backdates из `SINKING` — re-cast mid-rise не телепортирует тело на поверхность/днище, кривая проходит через текущую глубину бесшовно.
