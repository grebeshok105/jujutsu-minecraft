### 3) Позитивные наблюдения

- **Авто-экспирация без scrub — реализована буквально.** `MegumiShadowTrapRuntime.gripBodies:148-149` кладёт `MEGUMI_SHADOW_GRIP` на `8т` каждый тик внутри `insideCylinder`; вне цилиндра ре-apply прекращается и эффект спадает сам — ни одного `removeEffect(MEGUMI_SHADOW_GRIP)` в прод-коде нет (`grep removeEffect` находит только `TODO_SWAP_MOMENTUM` в `TodoStateLifecycle:64` и `TodoSwapMomentumRuntime:118`). Spec «без ручного scrub» соблюдён. `tick:117-138` закрывает лужу по `expiresAtGameTime`, `hasChunk`, `owner==null`, `level==null` — оба пути (event `clear` + tick `closeTrap`) идут в один `TRAPS.remove(ownerId, trap)` guard.
- **Vessel seam для атрибутов не эродировал.** `CharacterDefinition.applyAttributes/removeAttributes` default no-op, `CharacterCombatModifiers.applyForSelection:29-33` не знает имён vessel — только `JujutsuCharacters.all()` и `definition(selected)`. Добавление vessel требует только `Definition` + `JujutsuCharacters`/`JujutsuCharacterClients` — проверено `grep JujutsuCharacter.TODO` находит только definition'ы + self-check `TodoSwapMomentumRuntime`/`TodoBlackFlashRuntime` (допустимая self-filter форма, AGENTS.md E7).
- **Transient модификаторы + корректный reapply.** `TodoDefinition.addMultiplier:78-83` `addOrUpdateTransientModifier(..., ADD_MULTIPLIED_TOTAL)` — транзиенты не сериализуются, но `CharacterCombatModifiers.register:18-21` пере-применяет на `JOIN/AFTER_RESPAWN/AFTER_PLAYER_CHANGE_WORLD`. `removeAttributes` идемпотентен (null-guard) и вызывается для всех vessel перед `apply` — stale модификатор не переживает смену vessel. `onDeselected:74-76` делегирует в `TodoStateLifecycle.dropEverything` + `removeEffect(TODO_SWAP_MOMENTUM)` — momentum не странится на чужом vessel.
- **`ADD_MULTIPLIED_TOTAL` выбран осознанно для Todo melee, но не для `MEGUMI_SHADOW_GRIP` — там тоже верно.** `TodoDefinition` `MELEE 1.5×` как `+0.50` и `ATTACK_SPEED 0.85×` как `-0.15` через `ADD_MULTIPLIED_TOTAL` — корректно для vanilla `base 1.0 / 4.0`. Javadoc в `JujutsuEffects.java:25-26` явно отличает от `ADD_MULTIPLIED_BASE` (который дал бы `1.75×` вместо `1.25` поверх `1.50`). Для trap выбор `-0.75/-1.0` как `ADD_MULTIPLIED_TOTAL` — минимально инвазивный, без `AttributeModifier.Operation.ADDITION` который ломал бы баланс оружия.
- **Централизация в `*Profile`.** `TodoProfile.MELEE_DAMAGE_MULTIPLIER/ATTACK_SPEED_MULTIPLIER/SWAP_MOMENTUM_*` и `MegumiProfile.SHADOW_GRIP_*` — единственный source of truth, пинится `TodoProfileTest`/`MegumiProfileTest` (`-0.75`, `-1.0`, `1.50`, `0.85`). `TodoSwapMomentumRuntime.grant:49-50` читает `SWAP_MOMENTUM_WINDOW_TICKS=24`, `JujutsuEffects` читает `SWAP_MOMENTUM_DAMAGE_MULTIPLIER-1.0` — без дублирования литералов.
- **`MOVEMENT_SPEED -75%` как «квартал скорости» — feel верный.** Внутри `2.6` блока + `1.6` вертикали, gripped body может выйти пешком (не стан) — spec «never a stun». `JUMP 0` блокирует перепрыгивание бортика лужи, `insideCylinder:158-164` с `dy -1.0..1.6` не ловит пролетающих над головой.
- **Sink grip отделён от submerged walk.** `MegumiShadowMoveRuntime.begin:215-218` даёт `8т` (submerge) или `12т` (tap) grip только на sink, дальше `HIDDEN/SUBMERGED` — `hide()` без атрибутов, `EMERGE` — `reveal()`. Submerged walk без замедления — spec «once under, the walk is free», `tickSubmerged:305-315` не re-apply'ит grip.
