### 3) Позитивные наблюдения

- **Server-authoritative ticks — образцово.** Все касты (`TodoBoogieWoogieRuntime.tryCast`, `TodoStoneRuntime`, `MegumiSummonRuntime.tryToggle/trySic`, `NailTrapRuntime`, `SelfResonanceRuntime`) исполняются только на `ServerPlayer` + `ServerLevel.getGameTime()`. Клиент (`JujutsuKeybinds.sendCharacterAbility`) лишь шлёт `CharacterAbilityPayload` и локально suppresses повторный ввод по `ClientAbilityCooldowns.isReady` — никакого client-side движения, урона, телепорта. `hurtMarked=true` + `resetFallDistance` + `forceSetRotation` в `restoreMotionAndRotation:232-243` корректно форсят `ClientboundSetEntityMotionPacket` через `ServerEntity#sendChanges`.

- **Vessel stamp — закрывает десинк при смене сосуда.** `CharacterAbilityPayload:20` несёт `characterId`, `JujutsuNetworking.handleCharacterAbility:54` сравнивает с `CharacterSelectionManager.selected(player)` и silently отказывает. Меню применяет switch локально до подтверждения сервера — без штампа `R` Todo улетел бы как Hairpin Nobara. `CharacterSelectionManager.select` делает `onDeselected(old)` до `setAttached` + `onSelected(new)` — Todo статика дропается атомарно.

- **Атомарность свапов — preflight + commit + rollback.** `TodoSwapPlan/TodoTripleSwapPlan/TodoStonePlan.preflight(Optional)` вычисляет все `STRICT` destination до первого `teleportTo`. `commitTeleport.teleport` (injectable, `volatile` с комментом про cross-thread visibility) затем `place` sequential; при `!firstPlaced || !secondPlaced` — `rollback` в обратном порядке с логом `error`. `TodoBoogieWoogieRuntime.place:188-190` — единый `teleportTo` с `Set<Relative>` пустым (абсолютный). `TodoTransientState` единый владелец — каждый `clearPairSelection/clearStone/dropAll` идёт через него, `TodoStateLifecycle` — единственная точка регистрации хуков (death/respawn/dimchange/disconnect/stop/tick).

- **Target selection — детерминирован.** `TargetResolver:94-141` — ray-AABB с `ENTITY_HITBOX_INFLATE 0.35` + `SEARCH_INFLATE 2.5`, ранжирование `pierced → hitDistance/ angularOffset → entityId`. `angularOffset` нормализован по дистанции, `pierced` через второй `clip` без inflate — aim-assist не крадёт центр. EntityId tie-break убирает флип от iteration order. `TodoBoogieWoogieRuntime.isEligibleTarget:124-134` — `!isPassenger/isVehicle/isLeashed + !ArmorStand + finitePosition + sameLevel` — консистентно.

- **Pounce — per-dog cooldown + swept hit.** `MegumiDivineDogEntity.nextPounceReadyGameTime` per-dog (80 ticks), `pounceInFlight` guard, `MegumiPouncePolicy.canLaunch` — `active + currentPack + validOwner + currentTargetMatches + eligible + lineOfSight + distance 3-8 + deadlineReady`.
