### 3) Позитивные наблюдения

- **nail_icon.png — эталон.** 16×16 RGBA, 131 байт, присутствует по каноничному пути `textures/gui/hud/nail_icon.png` (проверено `audit/21-hud-target-esp.md` эталоном) — требование ТЗ выполнено без регресса.
- **Invisible rig — корректен.** Три `geckolib/models/character_skin/*.geo.json` — 1.12.0, 13 костей, 0 cubes — именно invisible humanoid rig для `CharacterSkinAnimationMixin` (skin animation bridge). Не путать с missing geometry; Codex прямо требует retention animation JSON при удалении visible Geo — соблюдено, `archive/character-player-gecko/manifest.txt` сохраняет provenance.
- **GeckoLib layout для player — load-bearing соблюдён.** Модели под `geckolib/models/**`, анимации под `geckolib/animations/**` — GeckoLib 5.2 их находит; старый `geo/**` path сознательно оставлен только для placeholder entities и архива, не для player — прошлый баг `Unable to find model file` закрыт.
- **Звуки — OGG Vorbis only, без mp3/wav.** Все 49 файлов `.ogg`, `sounds.json` 24 events с `subtitle` для 16 из них — консистентно с правилом "Sounds are OGG Vorbis". `JujutsuSounds.java` регистрирует все events из `sounds.json` (нет missing ogg для registered).
- **SDF/MSDF — зрелая реализация.** `SdfRenderer` с `nativeOrder()` direct buffer, `CachedOrthoProjectionMatrixBuffer("jujutsumod_sdf",1000,12000)` + `ModelView translate -11000`, `PAD=6`, `backup/restoreProjectionMatrix` в `finally`, `catch RuntimeException|LinkageError` — все уроки из `GUI-render-pipelines.md` применены. `JujutsuModClient:33` fail-fast `if (SDF_SHAPE==null) throw`, `MsdfFonts.bootstrap()` в init — без silent textless GUI.
- **Asset policy — source outside runtime packs реализован.** `processResources { exclude "source-assets/**" }` в `build.gradle` гарантирует что `source-assets/` (когда появится) не попадёт в jar; `archive/character-player-gecko/` вне обоих sourceSets — не пакуется (проверено `auditReleaseJarIsolation`). Placeholder provenance задокументирован в `PROVENANCE.md`+`THIRD_PARTY_NOTICES.md` с retained upstream notice Hadences.
- **Оригинальные дизайны для vessel.** `megumi.png` (64×64 RGBA) доставлен локально от owner, `todo.png`/`nobara.png` — project-specific; нет anime rips (photographic кадров) в `textures/entity/character/**` — spot-check трёх скинов показал pixel-art, не upscale скриншота.
- **VFX Core vs entity visuals — разделение соблюдено.** Transient combat VFX через `VfxCue→VfxDirector→*VfxRecipes`, persistent (`ProjectJjkNailEntity`, `TodoStoneEntity`, `MegumiDivineDog`) — через entity renderer/state, не через VFX Core — как требует Codex.
- **Lang parity.** `en_us.json` и `ru_ru.json` — по 140 ключей, diff 0, без дубликатов — после E5 фикса.

### 4) Вердикт

**PASS WITH CAVEATS**

Срез функционален для private dev: модели/анимации грузятся (player rigs по корректному GeckoLib 5.2 пути), текстуры 16×16/64×64 валидны, звуки OGG и зарегистрированы, SDF/MSDF пайплайны wired и fail-fast, `nail_icon.png` 16×16 на месте, anime rips отсутствуют, source-assets exclusion настроен. Критичных рантайм крашей (missing model file для player) нет — они касаются только placeholder entities из `geo/projectjjk`.
