### 3) Позитивные наблюдения

- **fabric-loader-junit внедрён образцово.** `build.gradle:81` `testImplementation "fabric-loader-junit:${loader_version}"`, `build.gradle:714` `useJUnitPlatform()`, `722` `failOnNoDiscoveredTests=true` — пустой JUnit discovery падает, а не зеленеет. `CharacterAbilityWireFormatTest.java:24-39` — эталон JUnit-контракта (append-only wire ids, ordinal==networkId, round-trip, unknown→null). `VesselBoundaryTest:50-68` выводит `VESSEL_IDS` из `JujutsuCharacter.values()` вместо хардкода — новый vessel покрыт днём создания.
- **JavaExec -ea аудит — редкий и честный.** `build.gradle:526-554` `verifyAssertionsEnabled` читает реальную `task model` (`tasks.withType(JavaExec).matching`), а не текст `build.gradle`; `T2.1` dynamic wiring `build.gradle:516-520` уже применён — новая verification программа попадает в `check` без второго ручного edit. Оба механизма — защита от silent pass, которую большинство проектов не имеет.
- **GameTest harness — production-путь, не мок.** `TodoSwapTestFixtures:setupTodoCaster` — `makeMockServerPlayerInLevel()` с `PlayerList.placeNewPlayer` + loopback channel; каст через `CharacterAbilityExecutor.tryCast(player, PRIMARY, true)` — тот же hop что `JujutsuNetworking.handleCharacterAbility` (`TodoAimedSwapGameTests:20-27` javadoc). `BodyState.capture()` пинит position+velocity+yaw/pitch/headYaw+fallDistance+dimension до/после — distinguish "restored" vs "never touched".
- **Seam для rollback — единственный детерминированный путь.** `TodoAimedSwapRollbackGameTests:214-219` `overrideCommitTeleport` — первый commit делегирует `PRODUCTION_COMMIT_TELEPORT` (тело реально движется), второй возвращает `false`; rollback `place`/`restore` идут мимо seam (`TodoBoogieWoogieRuntime` javadoc 31-40). `finally { restoreProductionCommitTeleport() }` — нет leak между тестами. Алкова-арена (`TodoAimedSwapRollbackGameTests:96-132`) с candidate-kill таблицей и LOS-pinning `hasLineOfSight` — отказ именно на `STRICT` preflight, а не на resolver.
- **Nobara tri-state — образцовый fix E10.** `NobaraAbilityResultGameTests:73-218` — `MessageRecordingPlayer` (override `displayClientMessage` → `TranslatableContents.getKey()`), `assertRecordedExactly( List.of(TRAP_NO_GROUND) )` — router не перезатирает `HANDLED_FAILURE` generic `no_target`, а `UNHANDLED_FAILURE` ровно один `no_target`. Cleanup `safe(()->clear)` в `finally` — нет leak cooldown/stagger.
- **Client canaries — честные границы.** `ClientLoadCanaryTest:30-54` — `isModLoaded` + `BuiltInRegistries.ENTITY_TYPE.containsKey(PRODUCTION_ENTITY_ID)` + `fabric.client.gametest` property + `computeOnClient` pre-world; `ClientObservationCanaryTest:30-62` — FLAT seed 1, `doDaylightCycle=false` + time 6000, `NoAi` pig, fixed 854x480 screenshot `observation_canary` — deterministic scene без pixel golden; `SdfGlassCanaryTest:28-48` — один `SdfRenderer.flush()` гоняет оба шейдера (legacy + glass negative highlight) — GLSL компилируется только в живом `RenderThread`.
- **qualityGate — единый gate без ручных списков в CI.** `build.yml:27` `./gradlew qualityGate --no-daemon` — то же что локально, без hand-maintained verification list в CI. `auditReleaseJarIsolation:603-680` сканирует `remapJar` на `jujutsu/mod/gametest/`, `jujutsu/mcpdev/`, `fabric-gametest` entrypoints — gametest не утекает в прод-артефакт.
